【本文】

「黒い画面が出た瞬間、そっとPCを閉じた」
という前科持ちのまるいちです。

（コードアレルギーです。ガチで。）

そんな僕が最近、
Claude Codeというツールを触ったんですが、

……これ、ちょっとヤバいんですよね。

「ヤバい」って言葉は使い飽きたと思うんですが、
他に言葉が浮かびませんでした。

AIでコンテンツを作る、発信する。

そのレベルの話じゃなくて、

「AIがAIを動かす」
「AIがファイルを読んで、書いて、判断して、完成させる」

という次の次のフェーズに、
もう入っているんです。

%name%さんも、
「AIってすごいなー」で止まってませんか？

僕もそこで止まっていた一人です。

でも、ある時ふと思ったんです。

道具を「使っている人」と、
道具に「気づいてすら」いない人、

半年後に差がつくのは、どっちか。

答えは見えてますよね。

だから今日は、言葉で説明するより、
見てもらった方が100倍早いと思って。

動画にまとめました。
