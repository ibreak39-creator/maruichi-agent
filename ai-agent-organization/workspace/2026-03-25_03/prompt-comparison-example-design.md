## 依頼の背景

X投稿で「能力差は小さい」という主張を補強するために使った比較例（小学生 vs オリンピック選手）が、主張と逆効果になっていた事例を元にスキル化。

### 修正前（NG）
```
人の能力差って、思ってるほど大きくないんですよね。
小学生とオリンピック選手の100mタイム差、たった数秒なんです。
```
問題: 小学生 vs オリンピック選手という比較はむしろ差が大きく見え、「差は小さい」という主張と矛盾する。

### 修正後（OK）
```
才能がある人より、
仕組みを持っている人が勝つ時代です。

人の能力差って、
思ってるほど大きくないんですよね。

例えば

運動能力のトップのオリンピック選手と
一般人の100mタイム差は、
たった数秒なんです。

見てわかる通り
変わらないんです。

差を生むのは
才能じゃなく「やり方」。

仕組みさえ変えれば、
ゆっくりやっても
速い人を追い抜けます。

AIはまさにその仕組みの
最強版だったりします。
```

### 改善ポイント
1. 比較対象を「小学生」→「一般人」に変更（主張と一致する比較軸に）
2. 「例えば」で具体例を明示的に導入
3. 「見てわかる通り / 変わらないんです。」で読者が納得する一押しを追加
4. 改行を入れて読みやすく
