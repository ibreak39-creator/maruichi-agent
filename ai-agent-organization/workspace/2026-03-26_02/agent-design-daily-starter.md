## 業務フロー

```
/todaystart 受信
  │
  ├─ Step 0: workspace セッション番号採番
  │
  ├─ Step 1: 直近メルマガを確認（inbox/04_アウトプット/00_メルマガ/01_一斉配信）
  │   ├─ 続きが書けそう → 続きテーマを決定
  │   └─ 難しい → 投稿ネタストック.md からネタ選定
  │
  ├─ Step 2: MAIL_CREATOR（文）に委譲
  │   └─ regular-newsletter スキルを使いメルマガ作成
  │
  ├─ Step 3: 投稿ネタストック.md からX投稿ネタ選定（メルマガとは別ネタ）
  │
  ├─ Step 4: X_POST_CREATOR（響也）に委譲
  │   └─ 適切なスキルでX投稿作成
  │
  └─ Step 5: 完了報告（件名・ネタ・保存先を一覧で提示）
```

---

## 設計上の工夫

- **メルマガネタの判断ロジック**: 直近メルマガがシリーズ継続か単発完結かを自動判断し、最適なネタ選択を実施
- **ネタの重複防止**: メルマガとX投稿に同じネタを使わないルールを明記
- **曜日考慮**: X_POST_CREATORの週間カレンダー戦略（水曜は軽め、土曜は重点）を引き継ぐ
- **エラーハンドリング**: ネタストック空・ディレクトリ不在・エージェント無応答の3パターンを定義
