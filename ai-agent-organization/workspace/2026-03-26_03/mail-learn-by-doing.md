# 「勉強してから始めよう」が、一番遠回りでした。

こんにちは、まるいちです。


先日、
Claude Codeという
AIツールを1日かけて
触り込んだんですよ。


Claude Codeって、
プログラマーじゃなくても使える
AIの開発ツールなんですが、

正直、
触る前は意味不明でした。


「黒い画面」が出てくるし、
英語の説明ばっかりだし、

「これ、自分に使えるのか……？」

って不安しかなかったんです。


でも、
とりあえず触ってみたんですよ。

YouTubeの解説動画とか
見ようと思ったんですけど、

「いや、もういいから触ろう」

って。


で、1日触り込んだ結果、
どうなったかというと……


「あ、こういうことか」

って、
感覚が掴めたんです。


これ、
めちゃくちゃ大事な話なんですけど、

僕が1日で感覚を掴めたのは、
「頭が良かったから」じゃないです。


「分からないまま触った」からです。


ここに、
多くの人が見落としている
落とし穴があると思っていて。


新しいツールとか、
新しいスキルに出会ったとき、

ほとんどの人は
こういう順番で動きます。


まず調べる。
次に勉強する。
そして理解してから始める。


一見、正しいですよね。


でも、
これがまさに落とし穴なんです。


なぜか？


「理解してから」って言ってる時点で、
永遠にスタートが切れないからです。


これ、
自転車の乗り方を
本で勉強するのと同じなんですよ。


自転車の構造、
ペダルの漕ぎ方、
バランスの取り方。

全部テキストで理解しても、
乗れるようにはならないですよね。


実際にまたがって、
転んで、
ふらつきながら進んで、

「あ、こうやってバランス取るのか」

って体で分かる。


AIツールも、
まったく同じ構図なんです。


調べる時間を
ゼロにしろとは言いません。


でも、

「分かってから始めよう」
という順番を、

「始めながら分かっていこう」
に変えるだけで、

体感で3倍くらい
吸収スピードが変わります。


僕がClaude Codeを
1日で使えるようになったのも、

「分からないけど、とりあえず触る」

を繰り返しただけです。


%name%さんは今、

「勉強してから始めよう」

って思っていること、
ありませんか？


もしあったら、
今日、5分だけでいいので、
触ってみてください。


「分からないまま触る」って、
めちゃくちゃ気持ち悪いんですけど、

その気持ち悪さの先に、
「あ、こういうことか」
っていう感覚が待っています。


それではまた、

明日の7時8分、
このメルマガでお会いしましょう～

いってらっしゃい！！
