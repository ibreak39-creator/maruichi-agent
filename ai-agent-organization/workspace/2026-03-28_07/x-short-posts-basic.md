## 投稿1

```
「AIを使えば稼げる」という人があまりにも多いですが、

正確には違います。

AIは「書く作業」を代替するだけで、「何を誰に届けるか」は代替できない。

プロンプトを磨いても稼げない人の根本は、戦略の問題です。ツールの問題じゃない。
```

**文字数**: 91文字

**使ったパターン**: 問題提起型（ねこ社長パターンA）×逆説構文（まるいちの文体）

**狙っているターゲット心理**: 「AIを使っているのにお金にならない」という行き詰まり感を持つ人。「プロンプトを磨けば解決するはず」という誤った方向への努力に気づかせ、「自分の問題は別のところにあったのか」という思考の転換を促す。

## 投稿2

```
偏見だけど、

AIで副業を始めた人の9割は「ツールの使い方」を学んで満足してます。

でも稼いでいるのは「ツールで誰の何を解決するか」を先に決めた人です。

順番が逆なんですよね。
```

**文字数**: 93文字

**使ったパターン**: 逆張り教育型（ねこ社長パターンD）×まるいちの「再現性・構造」価値観

**狙っているターゲット心理**: 「AIの使い方を学んでいる最中」の人が「自分はちゃんとやっている」という思い込みを持っている心理を先に言語化。「学び方の順番が間違っていた」という気づきで止まらせる。

## 投稿3

```
AIライティングを指導してて、ほぼ全員に共通する失敗があります。

「書く量を増やせば売れるようになる」という思い込みです。

量は関係ない。「誰のどんな問題を解決する記事か」が決まってない記事をどれだけ出しても、反応は動かないですから。
```

**文字数**: 110文字

**使ったパターン**: 一人称体験の入口フレーズ（writing-style-profile.md）×ターゲットの内なる言葉を先回り言語化（ねこ社長視点3）

**狙っているターゲット心理**: 「とにかく量を出せば結果が出るはず」と信じて疲弊しているAI副業初心者。自分の失敗の理由が言語化されていない状態で、まるいちが「それ、理由があるんだよ」と答えを持っているような信頼感を演出する。

## 投稿4

```
AIを「使いこなしている」と思ってる人へ。

ちょっと聞いてほしいのですが、

「AIに何かを作らせること」と「AIを使って価値を設計すること」は、まったく別の話です。

前者は作業の代行。後者が、お金になる理由です。
```

**文字数**: 104文字

**使ったパターン**: 対象者を絞り込んで呼びかける（パターン2フック）×逆説構文「〜ではない。〜だ」（まるいちの文体）

**狙っているターゲット心理**: 「AIを使ってはいるが、稼ぎにつながっていない」という中途半端な段階の人。「使えている」という自己認識と「稼げていない」という現実のギャップを突いて、思考の再整理を促す。

## 投稿5

```
くそぶっちゃけると、

「才能がないから稼げない」という人の99%は、才能の問題じゃないです。

「なぜ売れたか」を言語化できていないだけ。

再現できないから次に繋がらない。それだけです。
```

**文字数**: 90文字

**使ったパターン**: 逆張り教育型「くそぶっちゃけるけど」（ねこ社長パターンD）×まるいちの「再現性 > 才能」価値観

**狙っているターゲット心理**: 「自分には才能がない」という思い込みで行動をやめてしまっている人。才能論を一刀両断しつつ、「言語化・再現性」という具体的な解決策の入口を示す。まるいちの核心的価値観「再現性 > 才能」を最もシンプルに体現した投稿。
