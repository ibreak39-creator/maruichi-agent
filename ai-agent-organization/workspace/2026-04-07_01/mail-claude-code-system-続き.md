【件名】
「5分だけ」触ったら、朝が変わった

【本文】
こんにちは、まるいちです。

先日、「5分だけ遊んでみてください」
と書きました。

やってみましたか？

実は、あれには続きがあって。

「5分だけ触る」を実行した人が
どうなっていくか、少し話したいんです。

最初の5分は、正直よくわからない。

「何これ、すごそうだけど……
で、何ができるの？」って感じです。

でも、もう5分触ってみる。

気づいたら30分経ってた。

そして次の朝、
「昨日の続きやってみようかな」と
自然に思っている。

これが、習慣の始まりです。

「続けようと意識した」わけじゃなく、
「続きが気になったから触った」だけ。

でも、そのうちに何かが変わり始める。


たとえば、僕の朝は1年前とまるで違います。

【1年前】
毎朝ゼロからメルマガを書く
→ ネタを考えて、構成して、文字打って
→「これでいいかな……」と悩んで
→ 午前中が終わっていた

【今】
朝7時に起きたら、
メルマガもX投稿も
すでにできあがっている。

僕がやったのは最終チェックだけ。


この変化は、「続けよう」と決意したからじゃない。

楽しかったから触り続けた結果、
気づいたらシステムができていた。

それだけです。


「楽しさが習慣を生む」のではなく、
「楽しさがシステムを育てる」んです。


勉強でも、努力でもなく、
「昨日の続きが気になる」という感情が、
コンテンツ生成の仕組みを作った。

才能でもなく、
根性でもなく、
ただの「面白い」という感覚が。


%name%さんも、
5分触ってみたなら、

今日もう5分だけ、
続きを触ってみてください。

「次は何ができるんだろう」という好奇心が、
あなたの朝を変える最初の一歩です。


それではまた、
明日の7時8分、
このメルマガでお会いしましょう～

いってらっしゃい！！
