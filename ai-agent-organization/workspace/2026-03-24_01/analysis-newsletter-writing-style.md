# まるいちのメルマガ書き方分析レポート

**分析日**: 2026-03-24
**分析対象**: 19本（2026年2月10日〜3月22日配信分）
**分析者**: DATA_ANALYST（鑑）

---

## エグゼクティブサマリー

まるいちのメルマガは「自分の失敗・コンプレックスを開示する」ことを起点に、そこから普遍的な構造・法則を引き出し、読者の行動を変えることを目的とした設計になっている。構成は一貫しており「自己開示（恥ずかしい体験）→ 問題の再定義 → 法則化 → 読者への問いかけ → 行動指示」という黄金パターンが全体の約70%を占める。文体は短文・箇条書き・余白を多用した「読みやすさ最優先」設計で、1本あたりの読了時間は3〜5分を想定した長さ。ビジネス論・マインドセット系テーマが中心だが、必ず自分の日常エピソードをフックとして使うのが最大の特徴である。

## 1. 黄金構成パターン

全19本を分析した結果、以下の構成パターンが最も頻繁に使用されている（13本/19本、約68%）。

```
[黄金構成 Type A: 体験談→法則化型]

1. オープニング（自己開示・フック）
   └ 自分の失敗・コンプレックス・日常エピソードを正直に開示
   └ 読者が「自分も同じだ」と感じられる内容

2. 問題の核心（共感の深掘り）
   └ 多くの人が抱える共通の誤解・思い込みを提示
   └ 「〜と思っていませんか？」「〜と感じますよね」

3. 定義の書き換え・発見
   └ 常識・思い込みを逆転させる視点の提示
   └ 「でも、違うんです」「裏を返せば〜」

4. 法則の具体化
   └ 比喩・例え話（い・ろ・は・す、パズル、スーツ等）で抽象を具体化
   └ 箇条書きで構造化

5. 自分への適用
   └ 「僕もそうです」「だから今は〜」と自分ごとに落とす

6. 読者への問いかけ・行動指示
   └ 「%name%さんも〜ではないですか？」
   └ 「今日、1つだけ〜してみてください」

7. クロージング
   └ 「それではまた、明日の7時8分〜」
   └ 「いってらっしゃい！！」
```

**サブパターン Type B: 観察→洞察型**（5本/19本）
外部の出来事（Appleのメール、テレビ番組、美容室体験等）を観察し、そこから「稼ぐ・生きる」の本質を引き出す構成。

```
外部観察 → 「普通なら気づかないこと」を発見 → ビジネスへの翻訳 → 読者への問い
```

## 2. 書き出しパターン集

### パターン1: 自己キャラ紹介型（最多・約40%）

書き出しに「自分のコンプレックスや失敗をネタにしたキャラ紹介」を入れる。ユーモアを混じえながら自己開示するため、読者との距離が一気に縮まる。

**実例:**
- 「流行りのAIエージェントを使おうとして、謎の英語と黒い画面（コード）が出た瞬間にそっとPCを閉じたまるいちです。」（20260211）
- 「会社員の時は365日休みがいいなと思っていたまるいちです。」（20260217）
- 「チョコ高騰の影響で2026年はバレンタインにグミを送るのがトレンドになることを最近知ったまるいちです！」（20260213）
- 「僕、車の仮免許を取る時、『伝説』を作ったことがあるんです。」（20260225）

**特徴:** 「まるいちです」という締めでキャラを立てながら、フリとして機能させる。

### パターン2: 直接的な自己開示型（約25%）

コンプレックスや弱みを一言で宣言してから入る。読者の共感スイッチを最速で押す。

**実例:**
- 「僕は、社会不適合レベルの『飽き性』です。」（20260212）
- 「今日は、僕の直近のリアルをそのまま垂れ流そうと思います。」（20260214）
- 「今日のテーマはちょっと強めです。」（20260219）

### パターン3: 日常観察フック型（約20%）

日常の小さな出来事から始め、読者に「え、どういうこと？」という疑問を持たせる。

**実例:**
- 「昨日なんですけど、メールをぼーっと見てたら、Appleからこんな件名のメールが届いたんです。」（20260213）
- 「昨日、美容室に行ったんですが、そこで、『なぜ、人はその人を選ぶのか？』というビジネスの核心みたいなものに触れてしまったんですよね。」（20260218）
- 「ちょっと前にX（Twitter）でバズっていた、『ザ・ノンフィクション』というドキュメンタリー、見ましたか？」（20260222）

### パターン4: 数字・インパクト宣言型（約10%）

タイトルや冒頭で数字を使い、リアルな話であることを示す。

**実例:**
- 「ネットバンクの画面で、『ー1,000,000』の数字を見た瞬間、僕の2026年は、完全に変わりました。」（20260224）
- 「今日は、僕が月30万稼いでいたAIライターを捨ててコンテンツ販売やコンサルへ舵を切った本当の理由について話そうと思います。」（20260220）

## 3. 展開技法の特徴

### 3-1. 抽象→具体→再抽象の往復構造

まるいちのメルマガの核心的な技法。抽象的な主張を、身近な具体例で「見える化」し、最後にまた普遍的な法則として再抽象化する。

**例（20260215: い・ろ・は・す の話）:**
```
抽象: 「見せ方（ブランディング）が重要だ」
  ↓
具体: い・ろ・は・すの「くしゃっと潰せるボトル」という見せ方
  ↓
抽象: 「機能（水の味）ではなく体験（印象）で選ばれる構造を作れ」
```

**例（20260225: 車のエンスト話）:**
```
抽象: 「行動なき学びは無意味だ」
  ↓
具体: 仮免の実技試験でアクセルをベタ踏みしてエンストした話
  ↓
抽象: 「エンストしていい。失敗することで感覚が身につく」
```

### 3-2. 「多くの人 vs 成果が出ている人」の対比構造

読者を「うまくいかない人のループ」に共感させてから、「うまくいく人の行動」を提示する。

**典型的な展開（20260213）:**
```
うまくいかない人:  学ぶ → 満足する → 行動しない（ループ）
うまくいく人:     学ぶ → 自分ごとに落とす → 今やってることに1つだけ使う
```

### 3-3. 転換点の作り方

「でも、違うんです」「裏を返せば」「ここからが本題」という転換ワードを明示的に使い、読者の期待を裏切ることで洞察を印象づける。

**使用頻度の高い転換ワード:**
- 「でも、ある時ふと思ったんです。」
- 「でも、違うんです。」
- 「で、ここからが今日の本題。」
- 「裏を返せば、」
- 「なぜか？」（問いかけで読者を引き込む）
- 「実は〜」

### 3-4. 比喩・アナロジーの多用

抽象的な概念を、誰もが知っているものに例えることで理解の障壁を下げる。

| 説明したい概念 | 使った比喩 | 出典 |
|-------------|---------|------|
| 知識管理の仕組み | 冷蔵庫と料理人（NotebookLM × Gemini） | 20260211 |
| 体系的な学びの価値 | 1000ピースのパズルの完成図 | 20260223 |
| ブランディングの重要性 | い・ろ・は・すのボトル | 20260215 |
| 見せ方の改善 | サイズの合っていないスーツ | 20260222 |
| 行動不足の問題 | アクセルを踏まない仮免ドライバー | 20260225 |
| 過剰インプットの弊害 | 満杯のゴミ箱にゴミを押し込む状態 | 20260217 |
| 未使用の情報 | 腐らせる生鮮食品 | 20260221 |

## 4. 締めパターン集

### パターン1: 読者への問いかけ型（最多・約50%）

締めで読者に「今の自分」を振り返る問いを投げかける。自己投影を促しながら余韻を残す。

**実例:**
- 「%name%さんも、今の環境や基準値に満足していませんか？」（20260210）
- 「%name%さんは今、自分の人生を自分でコントロールできていますか？機能磨きに追われて、『自分』を磨くことを忘れていませんか？」（20260218）
- 「自分の性質に逆らった働き方をしていませんか？」（20260302）

### パターン2: 行動指示型（約30%）

「今日、1つだけ〜してください」という具体的なアクションを提示して終える。「やってみた」という読者体験を生む。

**実例:**
- 「今日は、その眠っている教材を1つだけでいいので、開いてみてください。そして、1行だけでもいいから実行してみる。」（20260221）
- 「今日は、派手に失敗するつもりで、何か一つ、アクセルを踏んでみてください。」（20260225）
- 「今日は、YouTubeを見るのをやめて、スマホを置いて、5分だけでいいので、外の空気を吸ってみてください。」（20260217）
- 「今日は、自分のフォルダを見返してみてください。」（20260223）

### パターン3: 宣言・メッセージ型（約15%）

まるいち自身の決意・変化宣言で締める。ストーリーの「続き」を読みたくなる余白を作る。

**実例:**
- 「僕の進化は、ここからさらに加速します。これからの『まるいち』を楽しみにしていてください。」（20260210）
- 「AIという最強の武器を使って、どうやって個人で稼ぎ切り、人生を自分の手でコントロールしていくのか。その『全体像』を、もっとリアルに届けていきます。」（20260303）

### パターン4: 固定フォーマット型（全本共通）

全19本の末尾に以下の固定フォーマットが入る。ルーティン感を作り「明日も来る」という習慣を形成する。

```
それではまた、
明日の7時8分、
このメルマガでお会いしましょう～

いってらっしゃい！！
```

### PSの活用（約60%）

約60%のメルマガにPS（追伸）がつく。PSの役割は以下の2種類：
1. **近況報告・人間性の開示**: コンサル体験、コンテンツ制作の舞台裏など
2. **商品・サービスのソフトな告知**: 「2026年ブースターパック」等の先出し案内

## 5. 文体・言語的特徴

### 5-1. 文章のリズムとテンポ

- **超短文が基本**: 1文が平均10〜20文字。最短は「でも、違うんです。」（10文字）
- **1段落1〜3行**: 情報の塊を小さく切り、視覚的な余白を作る
- **「。」の後に必ず空行**: テンポよく読み進めるための呼吸の間
- **改行の使い方**: 強調したい部分の前後で改行を入れ、そこを「引き算」で目立たせる

**例（20260212から）:**
```
でも、ある時ふと思ったんです。


これって本当に
「続ける力がない（能力不足）」
だけなのか？と。
```

### 5-2. よく使う表現・言い回し

**断定的な逆説表現:**
- 「でも、違うんです。」
- 「でも、全然そんなことはなかったんです。」
- 「裏を返せば、」
- 「〜ではありません。〜なんです。」

**読者を引き込む共感表現:**
- 「〜しますよね」「〜ありませんか？」「〜と思いませんか？」
- 「これ、やりますよね。」
- 「正直に言いますね。」

**自己開示の定型句:**
- 「実は〜」「正直〜」「本当に〜」（本音であることを示す）
- 「〜ましたw」「〜でしたww」（笑いを交えた自己開示）

**法則化の表現:**
- 「つまり、〜なんです。」
- 「これこそが、〜なんです。」
- 「結局これなんです。」

**数字・具体性:**
- 「5分だけ」「1つだけ」「1行だけ」（ハードルを極限まで下げる）
- 「10倍、100倍 いや、1,000倍大事」（誇張で重要度を強調）
- 実績数字（月30万、月100万、月160万、6,000万、27万軒）

### 5-3. 感情表現の特徴

- **ネガティブ感情を隠さない**: 「・・・グサッと来ました」「めちゃくちゃコンプレックスでした」「殴りたくなりましたww」
- **ポジティブへの転換を「感覚」で表現**: 「視界が一気にクリアになって」「音を立てて崩れ去った」「不思議と清々しい」
- **「めちゃくちゃ」「超」「かなり」を多用**: 感情の振れ幅を強調する副詞の多用

### 5-4. 句読点・記号の使い方

- **「、」の使い方**: 読点を少なくし、代わりに改行で区切る（読みやすさ優先）
- **「……」**: 沈黙・間を作る時に使用（「……はい。」「……グサッと来ました」）
- **「！！」**: クロージングや感情が高まった時（「いってらっしゃい！！」「最高でした！！」）
- **かぎ括弧「」**: 概念の名前付け・読者の心の声の再現に多用

## 6. タイトル設計の法則

### タイトルのパターン分類

**パターン1: 逆説・意外性型（最多・約35%）**

常識を裏切る一言で好奇心を刺激する。

- 「ボコボコにされたけど、最高でした」
- 「月30万稼いでいたAIライターを即捨てた理由」
- 「AI時代、スキルがある人ほど選ばれない理由」
- 「現代の9割は休み方が間違っている」

**パターン2: 自己開示・コンプレックス型（約30%）**

自分の弱みをタイトルにすることで、同じ悩みを持つ読者を引きつける。

- 「僕は、何をやっても続きません。」（句点が特徴的）
- 「すいません、今日は何もできません」
- 「できない言い訳って、いつまでやるの？」
- 「資格を取っても、何も変わりませんでした。」

**パターン3: 具体的金額・数字型（約20%）**

数字で実在感・リアルさを演出する。

- 「口座から－100万消えました」
- 「月100万稼ぐなら開始1秒でエンストをするべき」
- 「手取り20万の男に、6万円のスーツは必要か？」
- 「5万円でゴミを買ってしまっていた」

**パターン4: 問いかけ・読者限定型（約15%）**

読者を限定したり問いで思考を促す。

- 「『続かない人』にだけ読んでほしい話」
- 「1000ピースのパズルを、見本なしで完成させられますか？」
- 「AIエージェント、正直しんどくないですか？」

### タイトル命名の法則

1. **句点（。）を入れる**: 発言・告白のニュアンスを出す（「やめます。」「続きません。」「変わりませんでした。」）
2. **体言止めを避け、動詞・動作で終わらせる**: 「〜した理由」「〜するべき」「〜されない理由」
3. **金額の具体化**: 「月30万」「6万円」「－100万」などの具体数字
4. **「正直」「すいません」などの本音ワード**: 距離を縮める機能語

## 7. テーマ選びの傾向と法則

### よく扱うテーマの分類

| テーマ分類 | 本数 | 代表タイトル |
|----------|-----|------------|
| マインドセット・行動変容 | 7本 | 「できない言い訳って、いつまでやるの？」「飽き性」「エンスト」 |
| ビジネス論・稼ぎ方の構造 | 6本 | 「AIライター捨てた理由」「スキルがある人ほど選ばれない理由」「い・ろ・は・す」 |
| 日常体験→洞察 | 4本 | 「美容室」「Appleメール」「ザ・ノンフィクション」 |
| リアル近況・正直報告 | 2本 | 「今日は何もできません」「ライティングの発信、やめます」 |

### 日常体験→教訓への昇華パターン

まるいちが日常体験をテーマに昇華する手順は一定している：

```
1. 普通なら流してしまう日常の一場面に「引っかかり」を感じる
2. 「なぜこうなっているのか？」を構造で分析する
3. 「これ、稼ぐ・生きる・行動することと同じ構図だ」とマッピングする
4. 「多くの人はここで止まっている」という落とし穴を特定する
5. 読者に「じゃあ、あなたはどうする？」を問う
```

**素材の採取源:**
- 人との対話（経営者との面談、コンサル受講者との対話）
- テレビ・SNS（バズった投稿、Appleからのメール）
- 日常行動（美容室、車の教習、歩数計のデータ）
- 過去の失敗体験（資格、副業の歴史、コンテンツ購入）
- 自分のコンプレックス（飽き性、続かない、うつ）

### まるいちらしいテーマの「軸」

全テーマを貫く共通軸は以下の2つ：

1. **「機能・能力より、構造・見せ方・在り方が大事だ」**: スキルよりブランディング、努力より設計、知識より行動
2. **「自分の弱みや失敗が、むしろ本質を理解する鍵だ」**: 飽き性→構造理解速度、エンスト→行動の重要性、うつ→体の大切さ
