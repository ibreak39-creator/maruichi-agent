## フックパターン集（型別）

### 1. 本音暴露型（最強）
> **特徴**: "誰も言えない真実を自分だけが言う" という構造。信頼性と希少性を同時に生む。

```
誰も言わないからほんとのこといいます。泣いちゃったらごめん。
誰も言わないからほんとのこと言います。
ここだけの話、して良いですか…
あんまでかい声でいえないんですけど
```

**まるいち版テンプレ**:
```
誰も言わないからほんとのこと言います。[不都合な真実]
ここだけの話、[ターゲットが驚く事実]なんですよね。
```

---

### 2. 逆張り・逆説型（高インプ安定）
> **特徴**: 「常識を否定してから新真実を提示」。「そうなの？」という好奇心を刺激する。

```
なんかもう一周まわって〇〇最強説きた
バズは売り上げに関係…ありません！！！！！
別に私は「頑張りたい」からビジネスやってるわけじゃない。
〇〇は必要なかった。[代わりに必要なもの]だけでいい。
```

**まるいち版テンプレ**:
```
なんかもう一周まわって[意外なもの]最強説きた
[みんなが重視しているもの]は関係…ありません！！！
[努力・才能など] > [実は〇〇の方が大事だった]
```

---

### 3. 炎上予告型（エンゲージメント爆増）
> **特徴**: 「言いにくいことを言う」と宣言することで、続きを読まずにはいられなくなる。

```
めっちゃ敵作りそうなこというと
こんなこと言うと、批判殺到するかもだけど🥹
過激なこというけど
厳しいかもしれないですけど本音をいうと
```

**まるいち版テンプレ**:
```
めっちゃ敵作りそうなこというと、[業界の常識を否定する内容]
こんなこと言うと批判されるかもだけど、[ターゲットが心で思っていること]
```

---

### 4. 読者の心の声代弁型（共感・いいね誘発）
> **特徴**: ターゲットの頭の中にある言葉をそのまま書く。「自分のことだ」と感じさせる。

```
「あー、復帰したくない・・・この子の成長、1ミリも見逃したくない・・・」
「辞めようかなぁ…」って思うくらいなら
「専門スキルなんか1つもないし・・・」「履歴書に書けるの普通運転免許だけ」
「お金ないやばいー」「銀行口座怖くて見れない」
```

**まるいち版テンプレ**:
```
「[ターゲットが心の中で言っている言葉、不安・愚痴]」
↑ [こういう人へのメッセージ]
```

---

### 5. こっそり限定型（希少性・特別感）
> **特徴**: 「一部の人だけに教える」という演出で、読者を特別扱いする。

```
※こっそりクリスマスプレゼント🎄🤫
あんまでかい声でいえないんですけど
ここだけの話
こないだ500万バズ出したから、大声で言います！！！！（逆張りで使う）
【1つ前のポスト読んだフォロワーさん限定！】
```

**まるいち版テンプレ**:
```
※こっそり[ターゲットへのプレゼント]
ここだけの話、[驚きの事実]なんですよね。（大声では言えないけど）
```

---

### 6. 対比型（明暗を分ける）
> **特徴**: 「変わった人 vs 変われない人」「知ってる人 vs 知らない人」を対比させる。

```
✔︎AI時代に1000万稼げる人
✔︎一生0円で終わる人
決定的な違いがわかってしまいました。
```

**まるいち版テンプレ**:
```
✔︎[成功する人の特徴]
✔︎[失敗する人の特徴]
決定的な違いは[〇〇]の差だけ。
```

---

### 7. クイズ・煽り型（リプ誘発）
> **特徴**: 「答えを言わない」「わかる人いる？」で能動的参加を促す。

```
コンサルやってて1番困った衝撃ワード1位言ってもいい？
フォロワー数なんかよりも100倍くらい売り上げに関係する「数値」があるんですよね。なんの数値かわかる人いる？
```

**まるいち版テンプレ**:
```
[ジャンル]やってて1番[衝撃/笑える/驚いた]こと言ってもいい？
[達成するために]1番大事な「〇〇」、わかる人いますか？
```

---

### 8. ネガティブ告白型（引き込み）
> **特徴**: 「失敗・弱み・恥ずかしい過去」を正直に話すことで信頼感と共感を生む。

```
実は…わたしのせいで、[大変なことが起きた]
はあ…1人目の育休中にこのやり方に出会いたかった🥲
あの頃の私、まじで情弱すぎた。
```

**まるいち版テンプレ**:
```
実は…[失敗・恥ずかしい過去の告白]
あの頃の自分に教えてあげたい。「[本当に必要だったこと]」って。
```

## 分析メモ

- **短文・一言逆張り**が最もインプ効率が高い（12028 imp の投稿は20文字程度）
- **長文でもインパクトのある一行目**があれば読まれる（16245 imp は本文長いが冒頭が強烈）
- **育児×ビジネス**の文脈が彼女固有の強みで、まるいちはAI×思考設計で同様の独自文脈を持てる
- **「誰も言わない」「ここだけの話」「こっそり」** は強力な開幕ワードとして繰り返し使われている
- エンゲージメント（いいね・RT）はインプに比べて少ない投稿が多い → **無言で読まれる投稿が伸びる**傾向
- ✔︎リストは**視覚的にスキャンしやすく**、リスト型投稿は安定してインプが取れる
