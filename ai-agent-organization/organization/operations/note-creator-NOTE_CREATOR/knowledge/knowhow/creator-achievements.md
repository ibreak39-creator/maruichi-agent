## 数値実績（権威性の根拠）

- 副業歴8年 / 組織で月20万 → 個人で月160万達成
- AI講師として20回以上登壇（MAX約500人）
- 累計1,000名以上指導
- Kindle出版
- X開始18日で5万 / 2ヶ月で40万 / 月収最高160万
- AIライター初月から10万円 → ライターで月30万

- AIライター2ヶ月で月5万
- 教えて1ヶ月で60万円案件受注
- 18日で月2→10万 / 半年で50万

## 核心エピソード（共感の起点）

- 中学時代のいじめ体験（先輩・同級生から / サッカー部）
- 大学で「けいれん性発声障害」診断（声が出なくなる / 10年近くのコンプレックス）
- 国語の偏差値33〜37（ブログ7記事で挫折 / 25万払って辞めた）
- うつ病発症・休職・退職（2023年12月退職）
- 時給91円スタート（YouTube動画800本 / 1年で20万）
- 2025年1〜3月：平均歩数840歩のベッド生活

## 使い方の指針

- **権威性が必要なとき**: 数値実績（月160万・1,000名以上指導）を使う
- **共感が必要なとき**: 核心エピソード（偏差値33・うつ・時給91円）を使う
- **自己開示として**: 「国語の偏差値33の僕でもできたなら、あなたにできない理由なんてひとつもありません」という姿勢で

## 使用上の注意

- 実績の自慢にならないよう、「読者の変化を呼ぶ証拠」として使う
- エピソードは「先に弱さを見せて共感を取る」目的ではなく、「実体験が自然に滲み出す」形で使う
- 「国語の偏差値33の僕でもできたなら、あなたにできない理由なんてひとつもありません」という姿勢が根底
