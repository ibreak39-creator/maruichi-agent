## ファネル全体像

```
X投稿（価値観教育・認知・弱いフック）
    ↓  [X→メルマガ誘導 / X→note誘導: 週2回まで]

    ↓  [note内回遊: 前の記事・次の記事・シリーズ一覧]

    ↓  [無料記事3本で信頼構築]

    ↓  [CTAテンプレートA/B/C]
有料note / Tips教材（1,980円〜39,800円）
    ↓  [コンサル誘導]
個人コンサル（6ヶ月40万 / 1年75万）
```

## エージェント別の戦略レイヤー担当

| エージェント | 担当する戦略レイヤー | 主な役割 |
|------------|------------------|---------|
| **GUNSHI** | 全レイヤーの戦略立案 | ファネル設計・X/note運用戦略の壁打ち・KPI・PDCA |
| **X_POST_CREATOR** | ファネル第1層（認知） | X投稿4カテゴリ・価値観教育・メルマガ誘導 |
| **NOTE_CREATOR** | ファネル第2〜3層（信頼構築） | note記事7ステップ構造・タイトル設計・シリーズ設計 |
| **ARTICLE_STYLIST** | ファネル第3〜4層（購買導線） | 無料記事末尾の有料誘導文・回遊3点リンク |
| **ARTICLE_REVIEWER** | 全レイヤーの品質管理 | ブランディング逸脱チェック・ペルソナ適合性評価 |
| **DATA_ANALYST** | ファネル全体のKPI測定 | 各層の数値計測・遷移率分析・改善提案 |

## エージェント連携フロー

### X案件の処理

1. X_POST_CREATORに回す
2. 4カテゴリ（症状描写型A / 理想の姿型B / 認知の裏切り型C / 実験比較型D）に基づいて投稿を設計
3. カテゴリA・Dでnote誘導が必要な場合 → 対応するnote記事があるか確認
4. note記事が未作成の場合 → NOTE_CREATORにも並列でnote記事を依頼

### note案件の処理

1. NOTE_CREATORに記事を作成させる
2. 完成後 → ARTICLE_REVIEWERでブランドチェック
3. レビュー通過後 → ARTICLE_STYLISTで装飾・CTA配置・回遊3点リンク挿入
4. 同時にX_POST_CREATORでnote宣伝投稿を作成（並列実行可）

### 複合案件（X+note同時）

```
依頼受領 → BOSS: タスク分解
    ↓
並列実行:
  ├── NOTE_CREATOR: note記事作成
  └── X_POST_CREATOR: X投稿作成（カテゴリA + note誘導あり）
    ↓
完成後:
  ├── ARTICLE_REVIEWER: レビュー
  └── X_POST_CREATOR: note宣伝投稿の更新（URL確定後）
    ↓
ARTICLE_STYLIST: 装飾・CTA・回遊リンク挿入
```

## チームメイトへの指示時に確認すること

### GUNSHIへ（戦略壁打ち・企画立案時）
- `master-strategy.md` に今回の草案の全体像を構造化済み
- 戦略判断は4ペルソナ（タイガ・ハルカ・ケンジ・ミサキ）に基づく

### NOTE_CREATORへ（記事作成時）
- `article-creation-process.md` の7ステップ構造に従う
- 無料記事の場合: 必ず末尾に有料誘導文を入れること（AIライティング全書へ）

### X_POST_CREATORへ（X投稿作成時）
- `x-post-best-practices.md` の4カテゴリから適切なものを選択
- note誘導有無の判断基準を必ず確認してから作成

### ARTICLE_REVIEWERへ（レビュー時）
- `review-criteria.md` のブランドチェックリストを追加評価軸として使う
- NG表現リストに引っかかる場合は必ず指摘

### ARTICLE_STYLISTへ（装飾・CTA配置時）
- `cta-and-navigation.md` の3パターンのCTAテンプレートから選択
- 回遊3点リンクは必ず末尾に設置

---

## 重要な制約（絶対に守る）

- X投稿でのnote誘導は週2回まで
- NG表現（「正直、」/ 接続詞多用 / 保険ワード / Markdown混入 など）を含む成果物はリテイク
- CTA配置が強引な場合（「今すぐ買ってください」等）はリテイク
- 「まるいちさんがやれてるなら、自分もいける気がしてきました」という反応が出るコンテンツを目指す
