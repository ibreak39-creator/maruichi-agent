# ボコボコにされたけど、最高でした

こんにちは、まるいちです。


件名を見て、
 「え、まるいちさんってドMなの？」 って
思ったかもしれませんが、
 

最初に言っておきますが、
違いますとだけ
言っておきますねw


痛いのは嫌いですし、 
怒られるのも好きじゃありません。
 

そういう人がいたら
すぐに距離を取ります。
 

でも、先日は
本当にボコボコに
されたんです。
 

物理的にではなく、 
言葉と論理で。
 

なのに、 
不思議と清々しい。 

むしろ「最高」と感じてしまった。


先日、 知人の紹介で 
「とんでもない実績を持つ経営者」 と
お話しする機会をいただきました。

どれくらい凄いかというと、

・SNS集客ゼロで半年で売上6,000万 
・YouTubeの10万登録超えChを100個以上作成 
・誰もが知るトップYouTuberの指導役
・上場企業のマーケター


正直、
 住む世界が違う
「本物」のマーケターです。

1件当たり、億とかする
仕事を受注しているそうです。
 

最近、ありがたいことに
自分より経験豊富な経営者と
お話しする機会が増えているんですが、
 

今回で、 
僕の自信は、
木っ端微塵に砕かれましたw

僕のX運用を見て、 
開口一番、こう言われたんです。
 

「まるいちさんの発信、 
街角でティッシュ配ってる
おじさんと同じですよ」
 

・・・グサッと来ました。

さらに、こう続きます。
 

「便利だから受け取るけど、 
　誰もあなたのファンにはならない」
 

「メリット（機能）ばかり語って、 
　ベネフィット（理想の未来）がない」
 

「正直、つまらなそうに
　運用してますよね？」
 

もうね、 反論の余地が
ありませんでした。
 

全部、図星だったからです。
 

ここ最近の僕は、 
「伸び悩み」を感じていました。
 

実績を作るために、
 本当はやりたくないこともやって、 
周りに合わせて、自分を押し殺して。
 

てか、ここ30年間
自分の感情を抑えたり
周りに合わせ生きてきたので

デフォルトで
そんな感じなんです。
 

そして、冒頭で言った通り、 
ボコボコに言われているのに、

話していて
めちゃくちゃ
「楽しかった」んです。
 

なぜか？


「基準値」が、
一瞬で書き換わったからです。
 

自分の中で 「これくらいでいいや」 と
思っていた壁が、

圧倒的な実績を持つ人と話すことで
 

 「え、そんな視点で見てるの？」 
「そこまで考えてるの？」 と、
音を立てて崩れ去った。
 

視界が一気にクリアになって、 
「自分の現在地」と「進むべき道」が
ハッキリ見えた瞬間でした。
 

やっぱり、 
「誰と話すか」 
「誰の言葉を浴びるか」 
 

これだけで、
人生の難易度は変わります。
 

自分より 経験や知識がある人の
 「当たり前」に触れること。
 

これこそが、 
自分の殻を破る 一番の近道だと
痛感しました。
 

今の「ティッシュ配りのおじさん」を
卒業して、

 本当の意味で、
導ける発信者になるために。
 

僕の進化は、 
ここからさらに加速します。


これからの「まるいち」を
楽しみにしていてください。

 今の環境や基準値に
満足していませんか？
 

もし「ぬるま湯」にいるなら、 
熱湯に飛び込む勇気を持つこと。

それが、 現状打破の唯一の鍵です。
