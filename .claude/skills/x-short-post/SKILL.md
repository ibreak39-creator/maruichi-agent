## 投稿構成

### 基本構造（この順序を厳守）

```
[フック]
[本文]
[CTA]
```

### 文字数
- **140文字以内**に収める
- フック→本文→CTAを1投稿内で完結させる
- 文字数カウントは投稿本文のみ（改行含む）

---

## フック設計（最重要）

ターゲットに「これは絶対見なければ！」と思わせる強烈な1行を冒頭に置く。
writing-style-profile.md のフックパターンから文脈に合うものを選択する。

### パターン1: 読者の思い込みを否定する
```
「副業勢だから本業勢に負ける…」って思ってる人、完全に逆です。
```

### パターン2: 対象者を絞り込んで呼びかける
```
AIが思った通りに動いてくれない人へ。
```

### パターン3: 意外性のある断言
```
あんまり騒がれてないんですけど、〇〇はめちゃ化けると思います。笑
```

### パターン4: 問いかけ
```
この差、分かりますか？
```

### フックのNG例（使わない）
- 「今回は〜について解説します」
- 「〜のコツを紹介します」
- 「〇〇する人、めちゃ多いんですよね。」→ 読者が傍観者になる

---

## 本文設計

- 箇条書き（・）を使うか、1〜2文でゴリゴリの有益な内容を書く
- **視認性を最優先**（短い行、改行を適切に使用）
- 情報密度を高める。冗長NG
- 1段落は1〜2文が上限。長くなったら分割する
- 同じことを言い方を変えて繰り返さない。言い切ったら次へ進む

---

## CTA設計

読者が「何らかの行動を起こすきっかけ」「気づきを得る」ことが目的。
**CTAは1つに絞る**。

| CTAタイプ | 使用場面 | 例 |
|----------|---------|-----|
| 明示的（ブクマ推奨） | 情報を保存したくなるノウハウ系 | 「保存推奨です。」 |
| 明示的（リプください） | 議論・共有を促したいとき | 「あなたはどうですか？」 |
| 間接的（共感問いかけ） | 読者に気づかせたいとき | 「こんな経験ありませんか。」 |
| 行動促進 | 今すぐ動いてほしいとき | 「ぜひ試してみてください。」 |

---

## AI臭さ排除ルール（必須）

- 「一般的に」「多くの場合」→ 言い切る（「9割は」「ほとんどの人は」）
- 抽象語だけの主張NG → 具体的に何がどうなるか書く
- **体言止め禁止**: 文・投稿を体言止めで締めない。必ず「です・ます調」または自然な崩し語尾で終わらせること
- **語尾の連続禁止**: sentence-ending-patterns.md を参照し、同じ語尾を2回連続させない
- 「なんですよね」は全体で2回以内（短文なのでより厳格に管理する）
- 「--」は絶対使わない
- 締め定型句（「参考になれば幸いです」「いかがでしたでしょうか」等）は使わない
- 「〜について解説します」「〜を紹介します」などの前置きを入れない

---

## 3案作成ルール

**必ず3案を出力する**。それぞれ異なるフックパターンを使い、切り口を変える。

- 案1: パターン1または2のフック
- 案2: パターン3または4のフック
- 案3: 残りのパターン、または1〜4のどれかで切り口が最も異なるもの

同じ表現・同じ構造の繰り返しは禁止。3案それぞれに個性を持たせる。

---

## 出力形式

前置き・解説不要。投稿本文のみ出力する。

```
【案1】
[投稿本文]

文字数: ○文字

---

【案2】
[投稿本文]

文字数: ○文字

---

【案3】
[投稿本文]

文字数: ○文字
```

投稿本文作成後、必ず全案の語尾パターンを確認し、同じ語尾が2回連続していないかチェックすること。連続があれば別カテゴリ（A〜F）の語尾に差し替えて出力する。

## 補足:
- ハッシュタグは使用しない（方針）
- スレッド形式は禁止
- 一人称は「僕」
- 絵文字は最小限（0〜2個程度）。不要なら使わない
