## スタイルガイド

### 黄金構成（Type A: 体験談→法則化型 ／ 最頻出パターン）
```
1. オープニング（自己キャラ紹介 or 直接開示 or 日常フック）
   └ 「〇〇なまるいちです。」/ 「僕は、〇〇です。」/ 「昨日、〇〇したんですが」
2. 問題の共感・深掘り
   └ 「〜って思いますよね」「〜と感じますよね」
3. 転換点（定義の書き換え）
   └ 「でも、ある時ふと思ったんです。」「でも、違うんです。」
4. 法則の具体化（比喩・アナロジーを必ず使う）
   └ 誰もが知っているものに例える（い・ろ・は・す、パズル、スーツ等の手法）
   └ 「多くの人 vs うまくいく人」の対比を入れる
5. 自分への適用
   └ 「僕もそうです」「だから今は〜」
6. 読者への問いかけ・行動指示
   └ 「%name%さんも〜ではないですか？」
   └ 「今日、1つだけ〜してみてください」（ハードルを極限まで下げる）
7. 固定クロージング（変更禁止）
```

### Type B: 外部観察→洞察型
```
日常の一場面を観察
  → 「普通なら流してしまうことに引っかかりを感じた」という提示
  → 構造分析（なぜこうなっているか？）
  → ビジネス・人生の法則にマッピング
  → 読者への問い
  → 固定クロージング
```

### 書き出しパターン（4種類から1つ選ぶ）
- **自己キャラ紹介型**（最頻出）: 「〇〇していた/〇〇なまるいちです。」笑い・共感・キャラを1文で作る
- **直接開示型**: 「僕は、〇〇です。」で弱みを一言宣言
- **日常観察フック型**: 「昨日、〇〇したんですが、そこで〇〇に触れてしまったんですよね。」
- **数字・インパクト宣言型**: 「〇〇の画面で、『〇〇』の数字を見た瞬間〜」

### 書き方ルール
- **一人称**: 僕 / **二人称**: %name%さん
- 1文は平均10〜20文字の超短文
- 1段落は1〜3行。必ず空行で区切る
- **句読点の後は改行**（スマホ可読性のため）
- 逆説構文を多用する（「〜ではない。〜だ。」「でも、違うんです。」）
- 抽象→具体（比喩）→再抽象の往復を意識する
- 「……」で沈黙・間、「！！」で感情の高まりを表す
- 「」を多用（概念の名前付け・読者の心の声）

### 転換ワード（積極的に使う）
「でも、ある時ふと思ったんです。」「でも、違うんです。」「なぜか？」「裏を返せば、」「実は〜」「つまり、〜なんです。」「結局これなんです。」

### 使って良い言葉・表現
- 共感誘導: 「〜しますよね」「これ、やりますよね。」「〜ありませんか？」
- 本音開示: 「実は〜」「〜ましたw」「正直〜」
- ハードル下げ: 「5分だけ」「1つだけ」「1行だけ」
- まるいちワード: 再現性、構造、設計する側、自由、資産、長期的、本質

### 絶対に使わない言葉・表現
- 「正直に言います」「率直に言うと」（AI感が出る）
- 絶対、必ず、べき、根性、努力が足りない、才能がない
- 「いかがでしたか？」「〇〇についてお伝えしました」

### 冒頭フォーマット
```
こんにちは、まるいちです。

（本文）
```

### 締めフォーマット（必ず使う・変更禁止）
```
それではまた、
明日の7時8分、
このメルマガでお会いしましょう～

いってらっしゃい！！
```

### PSの活用（約60%のメルマガに入れる）
- 近況報告・人間性の開示（コンサル体験、制作の舞台裏など）
- または商品・サービスのソフトな案内（1〜3行）
- **本文に登場したツール・サービスをPSで自然につなぐパターン**（推奨）
  - 例：本文でClaude Codeに触れた → PS「ちなみに、僕が今使い込んでいる武器がClaude Codeです。〇〇が気になる方はこちら → URL」
  - **NG**: 本文と無関係なPSを突然入れる（唐突感が出る）
  - 本文のキーワードを1つ拾ってからPSの話題につなぐこと

## タイトルの付け方

| パターン | 例 |
|---------|---|
| 逆説・意外性型 | 「〇〇しているのに、〇〇できない理由」「AI時代、スキルがある人ほど選ばれない理由」 |
| 自己開示型 | 「僕は、〇〇が苦手です。」（句点を入れる） |
| 金額・数字型 | 「口座から−〇〇万消えました」「〇万円で〇〇してしまっていた」 |
| 読者限定型 | 「〇〇な人にだけ読んでほしい話」 |
| 情景フック型 | 「朝起きたら、〇〇が全部できあがっていた」（具体的な情景で「どういうこと？」を誘う） |

**共通ルール**: 句点（。）を入れて「告白のニュアンス」を出す。金額は具体的に。

### CTR最大化チェック（件名作成時に必ず確認）
- 「どういうこと？」と思わせる情報ギャップがあるか
- 「絶対に」「先に」など強度ワードで引きを強化できるか
- 本文冒頭と呼応していて、開いた後に期待を裏切らないか
- 弱ければ候補を3案出してユーザーに選ばせる
