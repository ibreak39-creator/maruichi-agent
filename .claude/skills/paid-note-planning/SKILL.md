- 依頼者条件: 有料noteで収益化したい情報発信者
- 制作者条件: マーケティング・コピーライティング・SNS動向に精通した戦略家

- `ai-agent-organization/shared/knowledge/hook-design-principles.md` → タイトル候補生成時に必ず参照。フックの2大要素・7パターンでタイトルの引きを強化する
- `ai-agent-organization/shared/knowledge/x-note-brand-strategy.md` → ブランドポジションとの整合性を確認する

# 実行内容:

{アイデア・テーマ}を受け取り、以下の**5ステップ**で有料note企画を設計してください。
各ステップを順番に実行し、最後に「元情報パッケージ」として統合出力してください。

---

## STEP 1：HARM分析（市場性の評価）

HARM（Health / Ambition / Relationship / Money）の4軸で、テーマがどの軸に該当するかを判定してください。

### 出力フォーマット:
```
該当するHARM軸: [H/A/R/M]（[軸名]：[サブカテゴリ]）

市場性スコア（各5点満点）:
- 悩みの深さ（お金を払ってでも解決したいか）: X/5
- 緊急性（今すぐ解決したいか）: X/5
- 拡散性（SNSで共感・シェアされやすいか）: X/5
- 競合の薄さ（差別化できる余地があるか）: X/5
合計: XX/20点

判定コメント: [売れる理由・売れにくい場合の懸念点を1〜2文で]
```

---

## STEP 2：マイクロペルソナ設計

「1,000円未満でこの記事を衝動買いする人」を解像度高く設計してください。
属性だけでなく、**購入直前の心理状態・トリガー**まで描写すること。

### 出力フォーマット:
```
【マイクロペルソナ】

基本属性:
- 年齢・性別・職業:
- 生活スタイル:
- SNSとの関わり方:

購入直前の状況:
- 今どんな状況にいるか（具体的場面）:
- 何をきっかけにこの記事に出会うか:
- タイトルを見て感じること:

心理プロファイル:
- 表層の悩み（口に出せる悩み）:
- 深層の欲求（本当に求めていること）:
- 購入をためらわせる心理的障壁:
- その障壁を超えさせるトリガー:

価格感度:
- 480円なら → [買う/迷う/買わない] + 理由
- 980円なら → [買う/迷う/買わない] + 理由
- 1,480円なら → [買う/迷う/買わない] + 理由
```

---

## STEP 3：購買動機の深掘り（なぜ今これが売れるのか）

表面的な「需要がある」ではなく、**「今このタイミングで売れる理由」**を社会背景・SNSトレンド・感情的文脈から掘り下げてください。

### 出力フォーマット:
```
【購買動機の深掘り】

社会的背景:
[このテーマが今注目されている社会的文脈・時代背景を2〜3文で]

SNSトレンドとの接点:
[X・InstagramなどSNSでどんな形で話題になっているか。バズ事例・共感パターン]

感情的文脈（購買の引き金）:
[どんな感情状態のときにこの記事を買いたくなるか。「このままじゃ〜」という危機感 or 「〜になりたい」という欲求]

競合との差別化ポイント:
[同テーマの無料記事・既存noteと比べて、この記事ならではの付加価値は何か]
```

---

## STEP 4：価格設定ロジック

以下の価格帯の特性を踏まえ、**推奨価格と根拠**を出力してください。

### 価格帯の基準（内部知識）:
| 価格帯 | 特性 | 向いているケース |
|--------|------|-----------------|
| 〜480円 | 衝動買い価格。「コーヒー1杯分」で決断できる | 悩みが広く浅い・フォロワーが少ない・初の有料note |
| 980〜1,480円 | 「ちゃんと解決したい」動機。信頼関係が必要 | 具体的ノウハウ・テンプレ・手法系。フォロワー500〜 |
| 1,980〜2,980円 | 「この人なら変われる」強い信頼が必要 | 体系的コンテンツ。フォロワー1,000〜・実績明確 |
| 3,000円〜 | ブランド確立が前提。コンサル的要素が必要 | 強いブランド・圧倒的実績がある場合のみ |

### 出力フォーマット:
```
【価格設定】

推奨価格: ○○○円

根拠:
- ペルソナの価格感度:
- コンテンツの情報密度・独自性:
- 現時点のフォロワー・信頼資産との整合性:
- 競合note・無料代替手段との価格差:

価格を上げる条件（将来的に）:
[どんな実績・信頼が積み上がれば価格を上げられるか]
```

---

## STEP 5：タイトル候補5案 + 推奨案

`hook-design-principles.md`を参照し、フックの2大要素（ターゲット明示 + 問題/欲求）を押さえたタイトル候補を5案生成してください。
各タイトルに「狙っているフックパターン」と「このタイトルが刺さる読者の心理」を添付すること。

### 出力フォーマット:
```
【タイトル候補】

案① [タイトル]
- 狙いフックパターン:
- 刺さる心理:

案② [タイトル]
- 狙いフックパターン:
- 刺さる心理:

案③ [タイトル]
- 狙いフックパターン:
- 刺さる心理:

案④ [タイトル]
- 狙いフックパターン:
- 刺さる心理:

案⑤ [タイトル]
- 狙いフックパターン:
- 刺さる心理:

★推奨案: 案○
推奨理由: [なぜこれが最も転換率が高いと判断したか]
```

---

## 最終出力：元情報パッケージ（note-creationへの引き渡し用）

STEP 1〜5の結果を統合し、`note-creation`スキルに直接渡せる形式で出力してください。

```
===== 有料note 元情報パッケージ =====

該当するHARM: [STEP1の結果]

ジャンル名（推奨タイトル）: [STEP5の推奨案]

なぜこれが売れるのか（購買動機となる深い背景）:
[STEP3の社会的背景 + SNSトレンド + 感情的文脈を統合して3〜4文で]

ペイン（悩み）:
[ペルソナの表層の悩みを、読者が実際に口にする言葉で1〜2文で]

マイクロ・ペルソナ（どんな人が買うのか）:
[STEP2のペルソナを2〜3文で圧縮]

推奨価格: [STEP4の推奨価格]円

持っている一次情報（記事に盛り込むエピソード・実績）:
[入力された一次情報をそのまま記載。未入力の場合は「→ ユーザーに確認」と記載]

差別化ポイント（この記事ならではの価値）:
[STEP3の差別化ポイント]

=====================================

次のステップ: このパッケージを `note-creation` スキルに渡して記事本文を作成してください。
```

---

# 絶対条件:
- STEP 1〜5を必ず順番に実行し、省略しないこと
- マイクロペルソナは「属性の羅列」にならず、**購入直前の場面と心理**まで描写すること
- 価格設定は根拠なしに決めない。必ず4つの判断軸（価格感度・情報密度・信頼資産・競合）から論拠を示すこと
- タイトル候補はフックパターンが5案とも被らないこと
- 最終出力の「元情報パッケージ」は、そのまま`note-creation`にコピペできる完成形で出力すること
- 指示の復唱・余計な補足は不要
