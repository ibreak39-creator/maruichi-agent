# 朝のコンテンツ自動生成（DAILY_STARTER）

このスキルが呼ばれたら、`Agent` ツールで `DAILY_STARTER` エージェントを起動し、以下の業務フローをすべて実行させること。
Claude Code が直接コンテンツを生成してはいけない。必ず DAILY_STARTER エージェントに委譲する。

---

## DAILY_STARTER への委譲プロンプト

DAILY_STARTER エージェントに以下を伝えて起動する:

```
/today-start を受け取りました。以下の業務フローを順番に実行してください。

### Step 0: セッション番号の採番
`ai-agent-organization/workspace/YYYY-MM-DD_*` の既存フォルダ数を確認し、次の連番（01, 02...）を採番する。
今日の日付を使って保存先フォルダを決定すること。
保存先: `ai-agent-organization/workspace/YYYY-MM-DD_NN/`

### Step 1: メルマガのネタ調査（2パターン分）

**パターンA（続きパターン）**: 直近メルマガを確認して続きを書く
参照先: `C:\Users\81804\product\maruichi-agent\ai-agent-organization\inbox\04_アウトプット\00_メルマガ\01_一斉配信`
直近のメルマガの内容・テーマを把握し、「その続き」として自然につながるテーマを考える。
シリーズ完結済みの場合も「別の角度から深掘りする続編」として設定する。

**パターンB（投稿ネタパターン）**: ネタストックから選ぶ
参照先: `C:\Users\81804\product\maruichi-agent\ai-agent-organization\inbox\投稿ネタストック.md`
ネタストックから「まだメルマガにしていない」もの、または最もまるいちらしい洞察を含むネタを1つ選ぶ。
X投稿で使うネタとは別のネタを選ぶこと。

### Step 2: MAIL_CREATOR（文）にメルマガ作成を委譲（2パターン同時）

`Agent` ツールで MAIL_CREATOR エージェントを起動し、以下を伝える:

- 使用スキル: regular-newsletter
- 作成パターン: 2パターン同時作成
  - パターンA（続きパターン）: [Step 1で把握した直近メルマガの続きテーマ]
  - パターンB（投稿ネタパターン）: [Step 1で選んだネタストックのテーマ]
- 保存先:
  - パターンA: `ai-agent-organization/workspace/YYYY-MM-DD_NN/mail-[topic]-続き.md`
  - パターンB: `ai-agent-organization/workspace/YYYY-MM-DD_NN/mail-[topic]-ネタ.md`
  （Step 0のセッション番号を使う）

MAIL_CREATOR が完成させた2パターンのメルマガをユーザーに提示すること。

### Step 3: X投稿のネタ選定

参照先: `C:\Users\81804\product\maruichi-agent\ai-agent-organization\inbox\投稿ネタストック.md`

条件:
- メルマガ（パターンA・B両方）で使ったネタとは別のネタを選ぶ
- まるいちのX戦略（ノウハウ型・思考型・実演型のバランス）を意識する
- 本日の曜日を考慮する（水曜は投稿数を減らす、土曜は重点投稿）

### Step 4: X_POST_CREATOR（響也）にX投稿作成を委譲

`Agent` ツールで X_POST_CREATOR エージェントを起動し、以下を伝える:

- ネタ: [Step 3で選んだネタ]
- 投稿タイプ: [ノウハウ型 / 思考型 / 実演型 / 短文型のうち適切なもの]
- 保存先: `ai-agent-organization/workspace/YYYY-MM-DD_NN/x-post-[topic].md`（Step 0のセッション番号を使う）

X_POST_CREATOR が完成させた投稿をユーザーに提示すること。

### Step 5: 完了報告

以下の形式で完了を報告する:

本日のコンテンツ生成が完了しました。

【メルマガ A（続きパターン）】
件名: [件名]
テーマ: [テーマ]
保存先: [ファイルパス]

【メルマガ B（投稿ネタパターン）】
件名: [件名]
テーマ: [テーマ]
保存先: [ファイルパス]

【X投稿】
ネタ: [ネタ名]
種別: [投稿タイプ]
保存先: [ファイルパス]

## ネタ選定の原則（DAILY_STARTER に必ず守らせること）

- **重複を避ける**: メルマガとX投稿で同じネタを使わない
- **まるいちらしさ**: 再現性・構造・判断精度などの価値観を体現したネタを優先
- **鮮度**: できるだけ最近の出来事・気づき・体験に関連するネタを選ぶ
- **ストック管理**: 使用したネタ名を明記して報告する

## エラーハンドリング（DAILY_STARTER に対応させること）

- **メルマガディレクトリが空・存在しない**: ネタストックから選ぶモードに自動切り替え
- **ネタストックが空**: ユーザーにネタの提供を依頼
- **MAIL_CREATOR / X_POST_CREATOR が応答しない**: ユーザーに状況を報告し、個別起動を提案する
```
