# 主張を補強する比較例の設計

## 入力:
- 主張 = {主張}
- 使おうとしている比較例 = {比較例}（任意。なければゼロから設計する）

## 前提条件:
- タスク: {主張}を補強するための比較例を設計または改善する
- 依頼者条件: X投稿・ブログ・メルマガなどで「比較例を使って主張を伝えたい」と考えている書き手
- 制作者条件: 論理構造と読者心理を両立させ、主張と比較例の整合性を検証できるライティング専門家

## 実行内容:

### Step 1: 主張の核心を特定する

{主張}から以下を抽出する:
- 主張の方向性（差が「大きい」vs「小さい」、「有利」vs「不利」など）
- 読者に変えてほしい認識（「実は〇〇なんだ」という驚き）

### Step 2: 比較例の整合性チェック

{比較例}が指定されている場合、以下を確認する:

**整合性チェックリスト**
- [ ] 比較対象は「主張の方向」と同じ印象を与えるか
  - 例: 「差は小さい」と主張するなら、比較例も「差が小さく見える」対象を選ぶ
  - NG例: 「差は小さい」と主張しながら「小学生 vs オリンピック選手」を比較 → むしろ差が大きく見える
  - OK例: 「差は小さい」と主張し「一般人 vs オリンピック選手」を比較 → 数秒差で差の小ささが伝わる
- [ ] 比較軸（何で比べているか）が読者に直感的に伝わるか
- [ ] 数字・事実を使っているか（「たった〇秒」「〇倍」など具体性があるか）
- [ ] 読者が「なるほど」と思える文脈で比較されているか

**整合していない場合は Step 3 へ進む。整合している場合は Step 4 へ進む。**

### Step 3: 比較例の修正または再設計

以下のルールに従って、主張と整合する比較例を設計する:

**比較例設計の4原則**
1. **主張と比較方向を一致させる**
   - 「差が小さい」を伝えたい → 実際に差が小さく見える対象を選ぶ（同カテゴリ内の比較）
   - 「差が大きい」を伝えたい → 実際に差が大きく見える対象を選ぶ
2. **比較対象の格差を意図的にコントロールする**
   - カテゴリが極端に違う対象（子供 vs 大人、素人 vs プロ）は、差の「大きさ」「小ささ」どちらの主張にも使いやすいが、直感的な印象に依存するため慎重に選ぶ
   - 同カテゴリ内（一般人 vs プロ選手）の方が「差の程度」を伝えやすい
3. **具体的な数字・事実で比較する**
   - 「少し違う」ではなく「5秒差」「1.2倍」など定量化する
4. **読者に「見てわかる通り」と言える状態にする**
   - 比較例を出した後、読者が自力で納得できるよう一押しの一文を添える
   - 例: 「見てわかる通り / 変わらないんです。」

### Step 4: 比較例を文章に組み込む

以下の構造で文章に組み込む:

```
[主張・テーマの提示]

[共感または問題提起]

例えば

[比較対象A]と
[比較対象B]の[比較軸]は、
[具体的な数字・事実]なんです。

[読者を納得させる一押し]

[主張の再提示・結論]
```

## 追加指示:
- 比較例は「主張のために選ぶ」という意識を持つ。直感的に面白い比較が、主張と逆効果になることがある
- 「例えば」で具体例を明示的に導入することで、読者が比較例と主張の関係を把握しやすくなる
- 読者が比較例を見た後に自力で納得できるよう、一押しの一文（「見てわかる通り / 変わらないんです。」など）を必ず入れる
- 改行を活用して、比較の要素を1行ずつ見せる（読みやすさ向上）
