  - h2見出し構造は使わない（流れるような文体で、区切り線「---」のみ使用）

# 実行内容:

{元情報パッケージ}と{記事の主要内容}を受け取り、以下の**3点を一括で出力**してください。

---

## 出力① タイトル最終案

`hook-design-principles.md`のフックパターンを参照し、転換率重視のタイトルを5案出力してください。

### 出力フォーマット:
```
【タイトル案】

案① [タイトル]（フックパターン：[パターン名]）
案② [タイトル]（フックパターン：[パターン名]）
案③ [タイトル]（フックパターン：[パターン名]）
案④ [タイトル]（フックパターン：[パターン名]）
案⑤ [タイトル]（フックパターン：[パターン名]）

★推奨案：案○
推奨理由：[なぜこれが最も転換率が高いか1〜2文で]
```

### タイトル設計の鉄則:
- ターゲット（誰向けか）を必ずタイトルに明示する
- 「何が手に入るか」または「何から解放されるか」を具体的に示す
- 数字（5つ・3ステップ・○○分など）は使えるなら積極的に使う
- ネガティブワード（「失敗」「ダメ」「苦しい」）は読者の心の声と重なると効果的
- 「〜する方法」「〜のコツ」などの汎用タイトルは避ける（差別化が弱い）
- 5案のフックパターンが被らないこと

---

## 出力② サムネ文言

note記事のカバー画像に載せるテキストを設計してください。
サムネは「文字だけでスクロールを止める」のが役割です。

### 出力フォーマット:
```
【サムネ文言】

メインコピー（大きく表示）:
[2〜4行、合計15〜30文字程度。改行位置も指定すること]

サブコピー（小さく表示）:
[1〜2行、10〜20文字程度]

補足テキスト（あれば）:
[「心理学×神経科学ベース」などの権威付け・差別化ワード]

デザイン指示:
[背景色イメージ・フォントの雰囲気・写真の有無など簡単に]
```

### サムネ設計の鉄則:
- メインコピーはタイトルの要約ではなく「最も刺さる一言」を抽出する
- 読者が「自分のことだ」と感じる言葉を優先する
- 煽り・大げさな表現は避け、「共感+具体性」で勝負する
- 文字数が多すぎると読めないので、視認性を最優先に

---

## 出力③ 販売ページ全文

以下の**販売ページ構成**に従って全文を作成してください。
文字数の目安：**1,500〜2,500文字**（スマホ2〜3分で読み切れる量）

### 販売ページ構成（この順番で書くこと）:

**[A] 冒頭フック（読者の心の声を1行目に置く）**
- hook-design-principles.mdの7パターンから最適を選ぶ
- 読者が「自分のことだ」と思う一文から始める
- 具体的な場面・時間・行動を描写してリアリティを出す
- 2〜4行で「あるある」の共感を積み上げる

**[B] 共感の深掘り（ペインをぐりぐり刺す）**
- ペルソナが感じている消耗・悪循環を言語化する
- 「こんなループ、ありませんか？」など共感フレーズを使う
- 「やっぱり自分はダメだ」などの心の声を代弁する
- 感情の吐露・具体的場面で「私の話だ」と感じさせる

**[C] 自責ブロックの解除（「あなたのせいじゃない」）**
- 読者が「意志が弱いから」「性格の問題」と思っている思い込みを崩す
- 「〜じゃないんですよ」「これ、脳の仕様なんです」など断言する
- 科学的根拠・専門知識があれば一文で添える（権威性）

**[D] 発信者の体験（信頼構築）**
- 著者自身が同じ悩みを経験したことを短く開示する
- 数字・具体的場面で「同じ経験者だ」と感じさせる（840歩など）
- 「だから書いた」という動機を自然につなげる

**--- （区切り線）**

**[E] この記事で書いていること（✔チェックリスト）**
- 記事の主要内容を「読者が手に入るもの」の視点で書く（機能ではなく便益）
- ✔ 記号で箇条書き。5〜8項目が適切
- 内容の説明ではなく「読んだ後の状態変化」を書く
- 科学的根拠・数字があれば括弧内に添える

**[F] こんな人に読んでほしい（ターゲット明示）**
- ペルソナが「自分だ」と感じる状況を3〜5点で箇条書き
- 状況・行動レベルで書く（「〜してしまう人」「〜が苦手な人」）
- 「自分ってこれだ」と思わせる解像度で

**[G] こんな人には向いていない（誠実さの設計）**
- 明らかに合わない人を正直に書く（2〜3点）
- 「重篤な症状がある場合は専門家へ」など誠実な一言を添える
- 「向いていない人」を明示することで逆に信頼が上がる

**--- （区切り線）**

**[H] 締め（理想の未来 + 価格の正当化）**
- 読み終えた後どんな状態になれるかを1〜2文で描く
- 価格を「〇〇円。〜〜と比べると〜〜」と自然な言い方で正当化する
- 背中を押す最後の一言で終わる（押し付けがましくなく）

---

# 口調・文体ルール（絶対厳守）:

- **ですます調を基本**とする（「〜です」「〜ます」「〜んですよね」「〜だったりします」）
- **体言止めは全体の10〜20%まで**。3文以上の体言止め連続は禁止
- **共感フレーズを積極使用**：「〜じゃないですか？」「〜だったりしますよね」「〜って経験、ありませんか？」
- **話しているように書く**：声に出して読んで自然な文章にする
- **場面描写で読者の頭にイメージを作る**：時間・場所・行動・感覚を具体的に
- **一人称は「僕」で統一**（「私」「筆者」は使わない）
- **AI臭い表現は禁止**：「重要」「効果的」「一概には」「一般的に」「さらに」の単独使用は避ける
- **安全クッション削除**：「〜かもしれません」「〜の場合もあります」は基本使わない
- 「」・()・：・／を本文中で乱用しない

---

# 出力順序:

**必ず以下の順番で一括出力すること（分割しない）:**

1. 【タイトル案】（5案 + 推奨案）
2. 【サムネ文言】（メイン + サブ + 補足 + デザイン指示）
3. 【販売ページ全文】（A〜H の流れで1,500〜2,500文字）

---

# 絶対条件:
- 3点（タイトル・サムネ・販売ページ）を必ず一括で出力すること。分割・ステップ確認は不要
- 販売ページはh2見出しを使わない。区切り線（---）のみで構造を作ること
- 「向いていない人」セクションは必ず入れること（信頼設計の核心）
- 価格の正当化は押し付けがましくなく、「〇〇円って、実は〜〜と同じくらいなんですよね」という自然な言い方で
- 発信者の一次情報・体験エピソードを必ず1箇所以上盛り込む（未入力の場合はknowledgeの実績情報から参照）
- 指示の復唱・余計な補足は不要
