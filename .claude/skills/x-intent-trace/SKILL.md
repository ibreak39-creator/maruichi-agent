# X投稿 意図解剖スキル（x-intent-trace）

## 使い方

```
/x-intent-trace [投稿URLまたは投稿テキスト]
```

引数なしで実行した場合は、分析したい投稿のURLまたはテキストを聞く。

---

## 進行フロー

### Step 1: 投稿の受け取り

- 引数にURLがある場合 → WebFetch or WebSearch で投稿内容を取得する
- 引数にテキストがある場合 → そのまま分析対象とする
- 引数なし or 取得失敗の場合 → 「分析したい投稿のURLまたはテキストを貼り付けてください」と聞く

取得した投稿テキストを分析前に一度そのまま表示し、「この投稿を分析します」と確認する。

### Step 2: 分析の実行

取得した投稿に対して、以下の6項目を順に分析する。

---

## 6項目の分析フレーム

### 1. 1行目の設計意図

「なぜこの開口一番か」を解剖する。

分析視点：
- どの感情・欲求・疑問を刺激しているか（好奇心 / 共感 / 恐怖 / 怒り / 驚き / 羨望）
- 誰に対して書かれているか（ターゲットの絞り方）
- 「さらに表示」を押させるための設計は何か
- 1行目を別の言い方にしたらどう変わるか（比較案を1つ出す）

出力形式：
```
【1行目の設計意図】
刺激した感情/欲求：[感情名]
ターゲット絞り：[どんな人が反応するか]
設計の核心：[なぜこの言葉・順番なのか]
別案との比較：「[元の1行目]」vs「[別の言い方]」→ [違いの解説]
```

---

### 2. 改行・段落設計の意図

「どこで止めて、なぜそこで止めたか」を解剖する。

分析視点：
- 改行の位置と読者の視線の動き
- 空白行（段落分け）の意図（呼吸 / テンポ / 緊張感の操作）
- 「次を読みたい」と思わせる切り方のパターン
- リズムの名前（短短長型 / 波型 / 断言→補足型 など）

出力形式：
```
【改行・段落設計の意図】
リズムの型：[型の名前]
重要な改行ポイント：[具体的な位置] → [意図の説明]
空白行の役割：[テンポ制御 / 感情の余白 / 情報の仕切りなど]
全体のリズム解説：[読者の視線がどう動くかの説明]
```

---

### 3. 言葉選び・比喩の意図

「なぜこの表現を選んだか」を解剖する。

分析視点：
- キーワードの選択理由（なぜこの単語か）
- 比喩・言い換えがある場合、その機能（具体化 / 感情移入 / 意外性）
- 使われていない言葉との比較（「〇〇という言い方もあったはず。なぜそうしなかったか」）
- 抽象と具体の切り替えパターン

出力形式：
```
【言葉選び・比喩の意図】
核心的なキーワード：[言葉] → [選ばれた理由]
比喩・言い換え：[表現] → [機能の説明]
使わなかった言葉との比較：「[別の表現]」ではなく「[元の表現]」→ [違いの効果]
抽象↔具体の設計：[どのように行き来しているか]
```

---

### 4. 構成の設計意図

「全体の展開がどう設計されているか」を解剖する。

分析視点：
- 構成パターンの特定（起承転結 / 問題→共感→解決→行動 / 逆説→理由→具体→結論 など）
- 各パートの役割と分量のバランス
- 読者の感情がどの順番で動くか（感情の旅路）
- 締め方の設計（断言 / 問いかけ / 余韻 / CTA）

出力形式：
```
【構成の設計意図】
構成パターン：[パターン名]
各パートの役割：
  [第1部] → [役割・意図]
  [第2部] → [役割・意図]
  [第3部] → [役割・意図]
  ...
感情の旅路：[読者の感情がどう動くかの流れ]
締め方の設計：[締め方の型] → [その理由]
```

---

### 5. フック型の命名

「この投稿のフック手法を一言で命名する」。

命名ルール：
- 2〜5文字の日本語で端的に表す（例：逆説型 / 数字暴露型 / 自己開示型 / 共感代弁型 / 問いかけ型 / 選別型 / 未来予測型）
- 命名後、その型の定義を1〜2文で説明する
- まるいちが同じ型を使うときの注意点を1つ添える

出力形式：
```
【フック型の命名】
型の名前：[型名]
定義：[この型が何をするものか、1〜2文]
まるいちが使うときの注意点：[1点]
```

---

### 6. 転用型カード（まるいち専用テンプレート）

「まるいちの投稿に今すぐ使える穴埋めテンプレート」を1枚作成する。

設計条件：
- まるいちのターゲット（AIで副業を始めたい人・月5〜10万の壁を越えたい人）に合わせる
- まるいちの世界観（再現性・構造・自立・長期的自由）に転用できる切り口にする
- 穴埋め箇所は [　　] で示し、ヒント（どんな内容を入れるか）を括弧外に添える
- テンプレートの下に「使用例」を1つ書く（まるいちが実際に書くとこうなる、という例）

出力形式：
```
【転用型カード】
フック型：[型名]

[テンプレート本文]
例：
[　　] だと思っていた。
でも実際は [　　] だった。
[具体的な理由や事例]。
だから僕は今 [　　] している。

---
使用例（まるいちが書くとこうなる）：
[実際の文章例]
```

---

## 分析後のアクション促進

6項目の出力が完了したら、最後に以下を表示する：

```
---
この投稿の型は「[フック型名]」です。

今すぐ転用型カードを使って投稿を作りますか？
→ 「はい」と言うと、テンプレートにまるいちの素材を当てはめた投稿案を1本作ります。
→ 「別の投稿も分析したい」と言うと、次の投稿を受け付けます。
```

---

## まるいちの文脈（分析の軸として常に意識する）

- まるいちはAIライター・AI講師・コンテンツクリエーター
- ターゲット：AIで副業を始めたい初心者、月5〜10万の壁を越えたいライター
- 届けるもの：情報ではなく「行動が変わる気づき」
- 世界観のキーワード：再現性、構造、判断精度、自立、長期的自由、設計する側
- 分析はすべて「まるいちがこの型を使うとしたらどう転用できるか」という視点で行う
- 競合の施策をそのまま真似る提案はしない。まるいちの世界観に合う形で翻訳する

---

## 注意事項

- URLで投稿が取得できない場合（ログイン必須・非公開など）は即座にテキスト入力を求める
- 分析は表面的な「良い投稿だね」で終わらせない。「なぜそうしたか」の意図まで掘り下げる
- 転用型カードは汎用テンプレートではなく、まるいちの世界観に特化して設計する
- フック型の命名は既存の型名があれば活用し、ない場合は新たに命名する
